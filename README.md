# 📚 毎朝3分！受験ニュース要約 Webアプリ

毎朝最新の「**中学受験**」「**高校受験**」「**大学受験**」ニュースを自動収集し、AIが30秒で読める「3行要約」にまとめて配信するWebアプリです。

**GitHub Actions** と **GitHub Pages** を組み合わせることで、**サーバー代ゼロ・API費用ゼロ（完全無料）** で永久に自動運用できます。

---

## 🌟 主な特徴

1. **3つの受験カテゴリーを網羅**:
   - 🏫 **中学受験**: 志願倍率、入試トレンド、学校改革、塾情報
   - 🎒 **高校受験**: 公立・私立入試日程、倍率速報、教育制度変更
   - 🎓 **大学受験**: 共通テスト、新課程、国公立・私立大動向、総合型選抜
2. **忙しい朝のための「30秒要約カード」**:
   - 📌 **核心要約**（一言サマリー）
   - • **重要ポイント**（2〜3行の事実まとめ）
   - 💡 **受験生・保護者へのアドバイス・影響**
   - 🔗 **元記事への直リンク**
3. **完全自動＆完全無料**:
   - 毎朝 **日本時間 午前6:00** に GitHub Actions が自動起動してニュースを更新
   - スマホのホーム画面に追加すれば、アプリのように1タップで毎朝の最新記事をチェック可能

## 🚀 無料公開・運用のセットアップ手順（約5分）

### ステップ 1: GitHub で新しいリポジトリを作成
1. [GitHub](https://github.com/) にログインし、右上の「+」から **「New repository」** を選択します。
2. リポジトリ名を入力します（例: `exam-news-daily`）。
3. **Public（公開）** を選択して「Create repository」を押します。

### ステップ 2: ファイルを GitHub にアップロード
このフォルダ（`exam_news_daily`）の全ファイルをリポジトリにプッシュ（またはWeb画面からアップロード）します。

```bash
git init
git add .
git commit -m "feat: 初回コミット - 受験ニュース要約アプリ"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/exam-news-daily.git
git push -u origin main
```

### ステップ 3: GitHub Pages（無料Web公開）を有効化
1. リポジトリの **「Settings（設定）」** タブを開きます。
2. 左メニューの **「Pages」** をクリックします。
3. **Build and deployment** の設定：
   - Source: **「Deploy from a branch」** を選択
   - Branch: **`main`** / フォルダは **`/docs`** を選択
4. **「Save」** を押します。
5. 数分後、画面上部に公開URL（例: `https://<あなたのユーザー名>.github.io/exam-news-daily/`）が表示されます！

### ステップ 4: 自動要約用の APIキー を設定（任意・推奨）
Gemini AI による自動要約を行いたい場合は、GitHub Secrets にキーを登録します：
1. リポジトリの **「Settings」** > 左メニュー **「Secrets and variables」** > **「Actions」** を開きます。
2. **「New repository secret」** をクリックします。
3. 以下を入力して保存します：
   - **Name**: `GEMINI_API_KEY`
   - **Secret**: お持ちの Gemini API キー
4. これで、**毎朝日本時間の朝6:00** に GitHub Actions が自動でニュースを取得・AI要約し、サイトを自動更新します！
   ※手動で今すぐ更新したい場合は、「Actions」タブから「毎朝6時 受験ニュース自動更新」を選び、「Run workflow」を押すだけでいつでも即時更新できます。

## 📱 スマホのホーム画面に追加する方法

スマホで一度サイトを開き、ホーム画面に追加すると専用アプリのように使えます：

* **iPhone (Safari)**:
  画面下の **共有ボタン（四角から矢印）** をタップ ➔ **「ホーム画面に追加」**
* **Android (Chrome)**:
  右上の **メニュー（︙）** をタップ ➔ **「ホーム画面に追加」** または **「アプリをインストール」**
